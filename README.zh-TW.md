# Apple Silicon 專用 Tartarus V2 控制程式

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

**Tartarus Light** 是適用於 Apple Silicon Mac 的原生 macOS 工具，支援 **Razer Tartarus V2**（USB `1532:022B`）燈光及裝置專屬按鍵映射。本專案為獨立開發，並非雷蛇官方軟體。

本頁提供繁體中文教學；**程式介面目前仍為簡體中文**。下文保留介面上的原始按鈕名稱，方便對照操作。

## 功能與系統需求

- 固定顏色、關燈、裝置內建完整光譜，以及自訂顏色循環。
- 燈光變更自動儲存、自動套用；啟動及指定 USB 位置的裝置重新連接後自動還原。
- 自訂循環支援 2–8 種顏色、順序調整、平滑漸變，以及每輪 2–60 秒。
- 一個來源鍵可同時輸出最多四個目標鍵，並附加 Command、Shift、Option、Control。
- 僅映射選定的 Tartarus V2 鍵盤介面，不會改動其他鍵盤的來源按鍵。
- 可選擇登入後啟動，並另外設定啟動後嘗試啟用映射。

需要 Apple Silicon Mac、macOS 13 或更新版本、Tartarus V2；從原始碼建置另需 Xcode Command Line Tools。目前實機測試環境為一台執行 macOS 27 的 Apple Silicon Mac；較舊系統、其他雷蛇型號及 Intel Mac 尚未實機驗證。

## 從原始碼建置與開啟

此儲存庫提供原始碼，未提供經 Apple 公證的安裝程式。

1. 若尚未安裝 Apple 命令列工具，先執行並完成安裝：

   ```sh
   xcode-select --install
   ```

2. 下載並建置：

   ```sh
   git clone https://github.com/harisucici/TartarusV2-For-Apple-chip.git
   cd TartarusV2-For-Apple-chip
   ./build.sh
   open "build/Tartarus Light.app"
   ```

腳本會建置 arm64 應用程式、加上本機臨時簽章、驗證簽章，並在 Apple Silicon 上執行檢查。輸出位於 `build/`，快取位於 `.build/`，不需要第三方套件。

請將程式放在固定位置；若要移至「應用程式」資料夾，請授權移動後的那份程式。本機簽章不等同 Apple 公證。重新建置或替換程式後，即使系統設定中的舊開關仍開啟，也可能需要重新加入權限。

## 教學一：設定燈光

1. 接上 Tartarus V2，開啟 **灯光效果** 頁面。
2. 選擇裝置；未顯示時按重新整理。程式綁定的是 USB 連接位置，更換連接埠後須重新選擇。
3. 選擇 **固定颜色**、**光谱循环** 或 **关闭**。
4. 固定顏色模式下，點 **背光颜色** 選色。變更會自動儲存及套用，不必另按套用。
5. 光譜模式下，**完整色谱** 使用裝置內建效果；**自定义颜色** 則由程式驅動。
6. 自訂模式中，點色塊修改顏色，按 **添加颜色** 新增，減號刪除，向上箭頭調整順序。至少保留兩種，最多八種；**一轮时长** 表示完整一輪的秒數。

自訂循環需要程式保持執行，每秒最多傳送十次易失性顏色更新；結束程式或進入睡眠後停止傳送，裝置停留在最後顏色。內建完整光譜由裝置自行執行。單獨使用燈光不需要輔助使用、輸入監控或管理員讀取程序。

## 教學二：權限與組合鍵映射

所有本程式的權限項目均使用同一名稱：**Tartarus Light**。

| 系統設定 | 用途 |
| --- | --- |
| 隱私權與安全性 → 輔助使用 | 一般使用者介面程序輸出映射按鍵。 |
| 隱私權與安全性 → 輸入監控 | 輸入讀取程序讀取選定的 Tartarus 鍵盤介面。 |
| 登入項目（選用） | 登入後自動開啟程式。 |

在本次測試的日文 macOS 中，輔助使用權限頁顯示為 **デバイスの制御とデータへのアクセス**，輸入監控為 **入力監視**。這些是不同的系統權限，仍須分別開啟。新版不再使用舊的 `TartarusInput` 或 `Tartarus Control` 項目；其他軟體的權限應依各自用途保留。

1. 開啟 **按键映射**，選擇要處理的 USB 裝置位置。
2. 按 **授予改键权限**，在上述兩個系統類別中允許本程式，必要時重新開啟程式。
3. 按 **添加映射**。可用選單指定來源鍵，或按 **识别来源**，完成管理員確認後按實體 Tartarus 按鍵。識別期間暫停該裝置的原始輸入，辨識完成自動釋放。**识别按键** 會持續辨識，直到按停止。
4. 選擇主要目標鍵；點選需要的 `⌘ Command`、`⇧ Shift`、`⌥ Option`、`⌃ Control`。使用 **添加同时按下的键** 加入其他同時按下的目標鍵。
5. 例：`1 → C` 加上 Command 為複製（`⌘C`）；再加 Shift 為 `⌘⇧C`；`2 → C + V` 會同時按住 C 和 V。**快捷模板** 提供複製、貼上及截圖範例。
6. 按 **保存映射**，再按 **授权启用改键**。管理員密碼僅在 macOS 系統視窗內輸入；等待顯示 **映射已启用**。
7. 點測試欄位，分別測試 Tartarus 和一般鍵盤。組合鍵會對目前聚焦的程式執行快捷操作，例如 `⌘A` 會全選文字。
8. 修改前先按 **停止 / 恢复**；程式處理 Escape 快捷鍵時也可用它停止。結束程式、拔除裝置、睡眠或切換登入工作階段也會停止映射。

按住來源鍵時會按住其目標，放開來源鍵時釋放。一般單鍵支援長按重複；快捷鍵及多鍵組合不會自動連發。未設定的支援按鍵依原義輸出。這是同時按下的組合，不是依序執行的巨集。

目前採用臨時管理員輸入程序，沒有安裝常駐背景服務。因此重新啟用映射或識別時，仍可能要求管理員確認；設定登入啟動不會跳過系統授權。

## 教學三：登入後自動執行

在燈光頁開啟 **登录后自动打开程序**，並依需要在 macOS「登入項目」批准。之後登入時會開啟程式並自動還原燈光。

若也要嘗試啟用映射，另開啟 **启动后自动尝试启用映射**。每次啟動只嘗試一次，必要時顯示管理員確認；取消或找不到裝置時不會反覆彈出。自動映射預設關閉。

## 常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 找不到裝置 | 檢查 USB 並重新整理；本版僅辨識 `1532:022B`。更換連接埠後重新選擇。 |
| `0xe00002c1` | 獨占鍵盤介面需要管理員權限，請使用程式提供的授權輸入模式。 |
| `0xe00002e2` | 在輸入監控中允許目前這份 **Tartarus Light**；舊 `TartarusInput` 權限不能替代。另確認是否有其他程式占用裝置。 |
| 系統顯示已允許，程式仍說未授權 | 更新或重新建置後，刪除舊記錄，再加入目前程式、開啟開關並重新啟動。 |
| 自訂燈光不再循環 | 保持程式開啟；睡眠及切換工作階段時會暫停。USB 回應失敗會停止並顯示錯誤，修改設定或重新連接後重試。 |
| 舊版刪除顏色時閃退 | 更新至最新版本；已修正刪除、重排後顏色選擇器仍回呼舊位置的問題。 |
| 快捷鍵在遊戲或特定程式中無效 | 檢查焦點、輸入法及目標程式是否接受合成按鍵；未保證所有程式相容。 |

僅接管選定 Tartarus 的鍵盤介面。macOS 的焦點與修飾鍵狀態仍會共用，按住映射出的修飾鍵時，同時輸入自然可能受影響；這不代表其他鍵盤的來源鍵被改寫。滑鼠按鈕、滾輪映射、循序巨集、Fn／Caps Lock 鎖定行為，以及部分媒體鍵和遊戲輸入尚未支援或驗證。

## 設定檔與開發

設定僅保存在本機，不納入 Git：

```text
~/Library/Application Support/TartarusLight/lights.json
~/Library/Application Support/TartarusControl/mapping.json
```

可遷移舊 `TartarusControl/profile.json` 格式，不會修改其他映射軟體的設定。

原始碼位於 `Sources/`：`Main.swift`、`Theme.swift`、`LightView.swift` 負責介面與模型；`LightController.swift`、`USBTransport.c/.h` 負責燈光；`MappingEngine.swift`、`MappingController.swift`、`MappingView.swift` 負責映射；`RootHelper.swift`、`PrivilegedInput.swift`、`IPC.swift`、`DeviceScope.swift` 負責限定裝置的輸入模式及通訊；`StartupController.swift` 管理登入啟動。

重新執行不向裝置送指令、也不注入按鍵的檢查：

```sh
"build/Tartarus Light.app/Contents/MacOS/TartarusLight" --self-test
```

檢查涵蓋協定、設定遷移、裝置範圍、組合鍵順序、共享目標釋放、停止釋放、IPC，以及 500 次顏色編輯回歸。本機另驗證了簡單改鍵與一般鍵盤隔離、統一權限名稱、自動燈光，以及循環中刪除和重排顏色；不代表所有遊戲、快捷鍵或系統版本均已驗證。
