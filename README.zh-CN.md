# Apple Silicon 版 Tartarus V2 控制程序

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

**Tartarus Light 0.5.1** 是面向 Apple Silicon Mac 的原生 macOS 工具，支持 **Razer Tartarus V2**（USB `1532:022B`）灯光和设备专属按键映射。本项目为独立开发，并非雷蛇官方软件。程序界面目前为简体中文；其他语言 README 翻译的是使用说明。

## 功能与要求

- 固定颜色、关灯、设备内置完整光谱和自定义颜色循环。
- 灯光修改自动保存、自动应用；启动及选定 USB 位置重新连接后自动恢复。
- 自定义循环支持 2–8 种颜色、顺序调整、平滑渐变及每轮 2–60 秒。
- 一个来源键同时输出最多四个目标键，可附加 Command、Shift、Option、Control。
- 仅映射选定 Tartarus V2 的键盘接口，其他键盘的来源键不被改写。
- 可选登录启动，并可单独开启启动后尝试映射。

需要 Apple Silicon Mac、macOS 13 或更新版本、Tartarus V2；从源码构建需要 Xcode Command Line Tools。实机测试在一台运行 macOS 27 的 Apple Silicon Mac 上完成；较旧系统、其他雷蛇型号和 Intel Mac 尚未实机验证。

## 构建与打开

仓库提供源码，暂未提供经过 Apple 公证的安装程序。

1. 如果尚未安装 Apple 命令行工具，先执行并完成安装：

   ```sh
   xcode-select --install
   ```

2. 克隆并构建：

   ```sh
   git clone https://github.com/harisucici/TartarusV2-For-Apple-chip.git
   cd TartarusV2-For-Apple-chip
   ./build.sh
   open "build/Tartarus Light.app"
   ```

脚本构建 arm64 应用、添加本地临时签名、验证签名，并在 Apple Silicon 上运行检查。应用输出到 `build/`，缓存位于 `.build/`，无需第三方依赖包。

请把应用放在固定位置；如果移动到“应用程序”文件夹，请授权移动后的那一份。本地签名不等于 Apple 公证。重新构建或替换应用后，即使系统设置的旧开关仍开启，权限也可能需要重新添加。

## 教程一：灯光

1. 接上 Tartarus V2，进入 **灯光效果**。
2. 选择目标设备，找不到时点击刷新。程序绑定 USB 位置，更换接口后要重新选择。
3. 选择 **固定颜色**、**光谱循环** 或 **关闭**。
4. 固定颜色下，使用 **背光颜色** 选色。修改即自动保存并应用，不需要再点应用。
5. 光谱循环下，**完整色谱** 是设备内置效果，**自定义颜色** 是程序驱动的自定义循环。
6. 自定义模式可点击色块改色，用 **添加颜色** 新增，减号删除，向上箭头调整顺序。至少两色、最多八色；**一轮时长** 设置完整一轮的秒数。

自定义循环要求程序保持运行，每秒最多发送十次易失性颜色更新；退出或睡眠后停止发送，设备停留在最后颜色。完整色谱由设备运行。仅使用灯光不需要辅助功能、输入监控或管理员读取进程。

## 教程二：权限与组合映射

本程序的各项权限名称均为 **Tartarus Light**。

| 系统设置位置 | 用途 |
| --- | --- |
| 隐私与安全性 → 辅助功能 | 普通用户界面进程输出映射按键。 |
| 隐私与安全性 → 输入监控 | 输入进程读取选定 Tartarus 的键盘接口。 |
| 登录项（可选） | 登录后自动打开应用。 |

本次测试的日文系统中，辅助功能权限页显示为 **デバイスの制御とデータへのアクセス**，输入监控为 **入力監視**。不同系统版本的名称可能有差异。两个权限类别需要分别开启。旧 `TartarusInput`、`Tartarus Control` 不再使用；其他软件的权限按各自用途保留。

1. 进入 **按键映射**，选择要处理的 USB 位置。
2. 点击 **授予改键权限**，在上述两个系统类别中允许当前应用，必要时重新打开程序。
3. 点击 **添加映射**。通过菜单选择来源，或点 **识别来源**、完成管理员确认后按实体键。识别期间暂停该 Tartarus 的原始输入，识别后自动释放；**识别按键** 会一直识别到手动停止。
4. 选择主目标键，开启需要的 `⌘ Command`、`⇧ Shift`、`⌥ Option`、`⌃ Control`。用 **添加同时按下的键** 添加其他同时按下的目标。
5. 例如 `1 → C` 加 Command 是复制（`⌘C`），再加 Shift 是 `⌘⇧C`；`2 → C + V` 是同时按住 C 和 V。**快捷模板** 提供复制、粘贴和截图示例。
6. 点击 **保存映射**，然后 **授权启用改键**。管理员密码只在 macOS 系统框内输入，等待显示 **映射已启用**。
7. 聚焦测试框，分别测试 Tartarus 和普通键盘。组合键会作用于当前应用，例如 `⌘A` 会全选文字。
8. 修改前点击 **停止 / 恢复**；应用能够处理 Escape 快捷键时，也可用它停止。退出、断开、睡眠或切换会话也会停止映射。

按住来源会按住目标，松开来源释放目标。普通单键可长按重复，快捷键及多键组合不自动连发。未配置的受支持按键保持原义。这是同时按下的组合，不是依次执行的宏。

当前使用临时管理员输入进程，没有安装后台常驻服务。每次启动映射或识别仍可能要求管理员确认；开启登录启动不会跳过这一步。

## 教程三：自动启动

灯光页开启 **登录后自动打开程序**，按需在 macOS“登录项”中批准，之后登录时会打开应用并自动恢复灯光。

映射需要另外开启 **启动后自动尝试启用映射**。每次启动只尝试一次，必要时弹出管理员授权；取消或设备不存在时不会反复弹窗。自动映射默认关闭。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 没找到设备 | 检查 USB 并刷新；本版仅匹配 `1532:022B`，换接口后需重新选择。 |
| `0xe00002c1` | 独占键盘接口需要管理员授权，请使用应用提供的授权输入模式。 |
| `0xe00002e2` | 在输入监控中允许当前 **Tartarus Light**，旧 `TartarusInput` 授权不能替代；同时检查其他软件是否占用设备。 |
| 开关已开，程序仍提示没权限 | 更新或重编译后删除旧记录，添加当前应用、开启开关并重启程序。 |
| 自定义循环停止 | 保持程序运行；睡眠和切换会话时会暂停。USB 回应错误会停止并显示原因，修改设置或重连后重试。 |
| 旧版删除颜色闪退 | 更新到 0.5.1 或更新版本，已修复删除、重排后颜色选择器访问旧位置的问题。 |
| 游戏或特定应用的快捷键不生效 | 检查焦点、输入布局和目标应用是否接受合成按键；未保证所有目标应用兼容。 |

只接管选定 Tartarus 的键盘接口。macOS 的焦点及修饰键状态是共享的，按住映射修饰键时可能正常影响同时输入；这不等于其他键盘的来源键被改写。鼠标按钮、滚轮映射、顺序宏、Fn／Caps Lock 锁定行为，以及部分媒体键和游戏输入尚未支持或验证。

## 配置与源码

配置仅保存在本机，不提交到 Git：

```text
~/Library/Application Support/TartarusLight/lights.json
~/Library/Application Support/TartarusControl/mapping.json
```

支持迁移旧 `TartarusControl/profile.json`，不会修改其他改键软件的配置。

源码位于 `Sources/`：`Main.swift`、`Theme.swift`、`LightView.swift` 是界面和模型；`LightController.swift`、`USBTransport.c/.h` 是灯光；`MappingEngine.swift`、`MappingController.swift`、`MappingView.swift` 是映射；`RootHelper.swift`、`PrivilegedInput.swift`、`IPC.swift`、`DeviceScope.swift` 是限定设备的管理员输入模式及通信；`StartupController.swift` 管理登录启动。

重新运行不发送设备指令、不注入按键的检查：

```sh
"build/Tartarus Light.app/Contents/MacOS/TartarusLight" --self-test
```

检查覆盖协议、配置迁移、设备范围、修饰键顺序、共享目标释放、停止释放、IPC、500 次颜色编辑回归。本机实测覆盖简单改键及普通键盘隔离、统一权限名称、自动灯光，以及循环中删除、重排颜色；不能据此宣称所有游戏、快捷键、设备和系统版本都兼容。
