# Apple Silicon 向け Tartarus V2 コントローラー

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

**Tartarus Light 0.5.1** は、Apple Silicon Mac で **Razer Tartarus V2**（USB `1532:022B`）のライティングとデバイス別キー割り当てを設定するネイティブ macOS アプリです。個人開発のプロジェクトであり、Razer の公式製品ではありません。

このページは日本語の操作ガイドです。**アプリの表示言語は現在、簡体字中国語です。** 以下では、画面上の中国語ラベルと日本語の説明を併記しています。

## 機能と動作環境

- 単色、消灯、デバイス内蔵スペクトラム、自分で選んだ色の循環。
- ライティング設定の自動保存・自動適用。起動時と、選択した USB 位置への再接続時にも復元。
- カスタム循環は 2～8 色、順序変更、滑らかな補間、1 周 2～60 秒に対応。
- 1 つの入力キーに最大 4 個の出力キーを同時に割り当て、Command・Shift・Option・Control を追加可能。
- 選択した Tartarus V2 のキーボードインターフェイスだけを対象とし、ほかのキーボードの入力キーは変更しません。
- ログイン時の起動と、アプリ起動後に割り当ての有効化を試みる設定。

Apple Silicon Mac、macOS 13 以降、Tartarus V2 が必要です。ソースからのビルドには Xcode Command Line Tools も必要です。実機確認は macOS 27 の Apple Silicon Mac 1 台で行っています。古い対応 OS、別の Razer 製品、Intel Mac は実機未検証です。

## ビルドと起動

このリポジトリはソースコードを提供します。Apple 公証済みのインストーラーは提供していません。

1. Apple のコマンドラインツールが未導入の場合、次を実行してインストールを完了します。

   ```sh
   xcode-select --install
   ```

2. リポジトリを取得してビルドします。

   ```sh
   git clone https://github.com/harisucici/TartarusV2-For-Apple-chip.git
   cd TartarusV2-For-Apple-chip
   ./build.sh
   open "build/Tartarus Light.app"
   ```

スクリプトは arm64 アプリを生成し、ローカルのアドホック署名と署名検証を行い、Apple Silicon 上でチェックを実行します。生成物は `build/`、キャッシュは `.build/` に置かれます。外部パッケージの導入は不要です。

アプリは同じ場所で使用してください。「アプリケーション」フォルダへ移す場合は、移動後のコピーに権限を付与します。ローカル署名は Apple 公証ではありません。再ビルドやアプリの置き換え後は、システム設定のスイッチがオンでも権限の再登録が必要になる場合があります。

## チュートリアル：ライティング

1. Tartarus V2 を接続し、**灯光效果**（ライティング）を開きます。
2. 対象デバイスを選択します。表示されない場合は更新ボタンを押します。USB の接続位置にひも付くため、ポート変更後は選び直してください。
3. **固定颜色**（単色）、**光谱循环**（スペクトラム循環）、**关闭**（消灯）から選択します。
4. 単色では **背光颜色** のカラーパネルで色を変更します。自動保存・自動適用されるため、適用ボタンはありません。
5. スペクトラムでは **完整色谱** がデバイス内蔵の全色循環、**自定义颜色** がカスタム循環です。
6. カスタム循環では各色を編集し、**添加颜色** で追加、マイナスで削除、上矢印で並べ替えます。2 色以上、8 色以下に設定できます。**一轮时长** は 1 周にかかる秒数です。

カスタム循環はアプリが実行し、毎秒最大 10 回の揮発性カラー更新を送信します。アプリ終了やスリープで更新が停止し、最後の色が残ります。内蔵スペクトラムはデバイス側で動作します。ライティングだけなら、アクセシビリティ、入力監視、管理者入力プロセスは不要です。

## チュートリアル：権限とキーの組み合わせ

本アプリの権限名は、いずれも **Tartarus Light** です。

| システム設定 | 用途 |
| --- | --- |
| プライバシーとセキュリティ → アクセシビリティ関連の制御権限 | 通常ユーザーで動く画面側プロセスが、割り当てたキーを出力します。 |
| プライバシーとセキュリティ → 入力監視 | 入力プロセスが選択した Tartarus のキーボードインターフェイスを読み取ります。 |
| ログイン項目（任意） | ログイン後にアプリを開きます。 |

実機確認に使用した日本語 macOS では、アクセシビリティ関連の権限ページは **デバイスの制御とデータへのアクセス**、入力監視は **入力監視** と表示されます。OS のバージョンによって名称が異なる場合があります。別々の権限なので、両方のスイッチを有効にしてください。旧版の `TartarusInput` と `Tartarus Control` は使用しません。ほかのアプリの権限は、そのアプリの用途に従って管理してください。

1. **按键映射**（キー割り当て）で対象の USB 位置を選びます。
2. **授予改键权限**（権限を要求）を押し、上記の両方でこのアプリを許可します。必要に応じてアプリを開き直します。
3. **添加映射**（割り当てを追加）を押します。メニューで入力キーを選ぶか、**识别来源**（入力元を識別）を押し、管理者確認後に Tartarus の実キーを押します。識別中は対象デバイスの通常入力を一時的に止め、取得後に解放します。**识别按键**（キーを識別）は停止するまで継続します。
4. メインの出力キーと、必要な `⌘ Command`・`⇧ Shift`・`⌥ Option`・`⌃ Control` を選択します。**添加同时按下的键** で同時に押す出力キーを追加できます。
5. 例：`1 → C` に Command を付けるとコピー（`⌘C`）、さらに Shift を付けると `⌘⇧C` です。`2 → C + V` は C と V を同時に押します。**快捷模板** にはコピー・ペースト・スクリーンショットのプリセットがあります。
6. **保存映射**（保存）、**授权启用改键**（承認して有効化）の順に押します。管理者の認証情報は macOS のシステムダイアログ内にだけ入力し、**映射已启用**（有効）になるまで待ちます。
7. テスト欄にフォーカスし、Tartarus と通常のキーボードをそれぞれ確認します。ショートカットは現在のアプリに作用します。たとえば `⌘A` は文字を入力せず、テキストを全選択します。
8. 変更する前に **停止 / 恢复**（停止・復元）を押します。このアプリが Escape ショートカットを処理しているときは、Escape でも停止できます。終了、切断、スリープ、セッション切り替えでも停止します。

入力キーを押している間は出力キーも押した状態となり、離すと解放します。通常の単一キーはリピートしますが、ショートカットや複数キーの組み合わせは自動リピートしません。未設定の対応キーは元の意味で出力します。これは同時押しであり、順番に実行するマクロではありません。

現行版は一時的な管理者入力プロセスを使用し、常駐デーモンはインストールしません。有効化や識別のたびに管理者確認が必要になる場合があります。ログイン起動を設定しても、この確認は省略されません。

## チュートリアル：ログイン時の起動

ライティング画面の **登录后自动打开程序**（ログイン後に開く）をオンにします。必要であれば macOS のログイン項目で承認してください。ログイン時にアプリが開き、ライティングが自動復元されます。

割り当ても有効にしたい場合は、別途 **启动后自动尝试启用映射**（起動後に有効化を試みる）をオンにします。起動ごとに 1 回だけ試み、必要に応じて管理者認証を表示します。キャンセル時やデバイス不在時に認証を繰り返すことはありません。自動割り当ては初期状態ではオフです。

## トラブルシューティング

| 状況 | 確認する内容 |
| --- | --- |
| デバイスが表示されない | USB 接続と更新ボタンを確認します。対応 ID は `1532:022B` のみです。ポート変更後は選び直します。 |
| `0xe00002c1` | キーボードインターフェイスの排他的な取得には管理者権限が必要です。アプリの承認付き入力モードを使ってください。 |
| `0xe00002e2` | 現在の **Tartarus Light** を入力監視で許可してください。旧 `TartarusInput` の許可は代用できません。ほかのアプリによるデバイスの占有も確認します。 |
| 許可済みなのにアプリは未許可と表示する | 更新や再ビルド後は旧項目を削除し、現在のアプリを追加し直して有効にし、再起動してください。 |
| カスタム循環が止まる | アプリを開いたままにします。スリープやセッション変更で一時停止します。USB エラーで停止した場合は、設定変更または再接続で再試行します。 |
| 古い版で色を削除すると終了する | 0.5.1 以降に更新してください。削除・並べ替え後の古いカラーピッカーコールバックによるクラッシュを修正しています。 |
| ゲームや特定アプリでショートカットが効かない | フォーカス、入力レイアウト、合成キー入力への対応を確認します。すべてのアプリでの動作は保証していません。 |

取得するのは選択した Tartarus のキーボードインターフェイスだけです。ただし macOS の修飾キー状態とフォーカスは共有されるため、割り当てた修飾キーを押しながら別の入力を行うと、通常どおりその影響を受けることがあります。ほかのキーボードの入力キーを割り当て直す動作ではありません。マウスボタン、ホイール割り当て、順次マクロ、Fn/Caps Lock のロック動作、一部のメディアキーやゲーム入力は未対応または未検証です。

## 設定ファイルと開発

設定はローカルに保存され、Git には含めません。

```text
~/Library/Application Support/TartarusLight/lights.json
~/Library/Application Support/TartarusControl/mapping.json
```

旧 `TartarusControl/profile.json` 形式からの移行に対応し、ほかのキー割り当てアプリの設定は変更しません。

ソースは `Sources/` にあります。`Main.swift`・`Theme.swift`・`LightView.swift` は画面とモデル、`LightController.swift`・`USBTransport.c/.h` はライティング、`MappingEngine.swift`・`MappingController.swift`・`MappingView.swift` はキー割り当てを担当します。`RootHelper.swift`・`PrivilegedInput.swift`・`IPC.swift`・`DeviceScope.swift` は対象を限定した管理者入力モードと通信、`StartupController.swift` はログイン起動を担当します。

デバイスへの命令送信やキー注入を行わずにチェックを再実行できます。

```sh
"build/Tartarus Light.app/Contents/MacOS/TartarusLight" --self-test
```

チェックにはプロトコル、設定移行、デバイス範囲、修飾キー順序、共有出力キーの解放、停止時の解放、IPC、500 回の色編集回帰を含みます。開発用 Mac では単純な割り当てと通常キーボードの分離、権限名の統一、自動ライティング、循環中の色削除・並べ替えも確認しました。すべての OS、ゲーム、ショートカットやデバイスの互換性を示すものではありません。

プロトコルの参考：[OpenRazer](https://github.com/openrazer/openrazer)。関連団体との提携や推奨を意味するものではありません。
